# ApiaryFlow 操作 / Operations

知华科技（上海如静知华信息科技有限公司）· https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。

## 初次使用 / Initial setup

管理员登录后，在账号页增加管护、独立复核和接收人员。岗位权限和团队范围分开；设置页提供团队/IANA时区、字典、菜单、参数。首次无蜂群事实。创建蜂场，填写真实位置描述和容量；建立蜂群编号、分类、来源、管护人及建档日期。编号和蜂群当前位置不能普通编辑，位置通过交接改变。

Add keeper, independent reviewer and receiver accounts. Configure team/zones, categories, menus and capacity. Register apiaries and colonies. Stable codes cannot be rewritten; location changes through handover.

## 现场观察 / Inspection

管护人员进入巡检页新增，选择本人蜂群，填写观察日期、整数框数、是否见王、贮蜜及子脾观察和说明，指定独立复核人。保存草稿后详情送审。复核人登录核实，或附说明退回。待审状态下管护人可撤回修改。已核实记录只有“追加修订”，不会直接进入编辑；修订保留原日期/蜂场/蜂王上下文，在新记录核实前原记录仍有效。

Keepers save observed facts as drafts and submit. Assigned reviewers verify or return with notes. Corrections append and preserve original context; the old record remains current until the correction is verified.

## 分群、换王和退出 / Colony events

协调人员打开蜂群详情，登记分群时填写新蜂群编号和名称、实际日期、事实说明；新蜂群继承当时蜂场、管护和分类，不推定蜂王编号。换王填写新蜂王编号，事件保留旧/新值。退出保留历史并禁止后续业务。事件和来源不能普通删除；只有未使用误建登记可删除。

Register daughter colonies with new identity and declared parent, without inferred queen identity. Requeen events preserve old/new labels. Retired colonies retain history. Only never-used erroneous registrations can be deleted.

## 转场交接 / Transfer

编制者选择同团队源/目标蜂场、计划日期、不同移出人和接收人，勾选1–50个可用蜂群。发布会冻结清单并占用目标预留。发布后不能直接编辑，只能在实际移出前取消。移出人检查现场后确认实际日期与说明，状态变途中；接收人实际核对后确认，当前位置才变。管理员不能代办。途中不提供取消或自动接收。

The coordinator plans same-team relocation. Release freezes manifest and reserves capacity. Sender confirms actual departure; receiver confirms actual receipt. Location changes only at receipt. Cancellation is allowed only before departure.

## 查询与导出 / Query and export

列表支持名称/编号/说明搜索、状态过滤、排序和15条分页。详情查看实际状态和历史，巡检核实后可CSV导出，转场发布后可导出。已取消发布转场仍可导出原清单和当前取消状态；未发布草稿不导出。统计只描述授权数据，不推导疾病、蜂王绩效或商业收益。

Search, filter, sort and15-row UI paging. Verified inspections and released manifests provide CSV. Cancelled previously released transfers retain their manifest and cancellation status; unreleased drafts cannot export. Reports are descriptive, not diagnosis or economic performance conclusions.
